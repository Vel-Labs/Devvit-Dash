# Submission Screenshot Plan

Status: capture plan only. Public submission images must come from the final live Devvit candidate after T090; local mocked GoalBuddy evidence is not submission media.

## Capture rules

- Capture the exact submitted app version in Reddit or its versioned Devvit WebView.
- Remove `?qaCapture=1`, browser developer chrome, test overlays, mock usernames, tokens, and private URLs.
- Use real app state that the caption describes; never seed metrics only for a screenshot without disclosure.
- Prefer one clear claim per image and provide useful alt text.
- Keep text readable at Devpost gallery size and preserve the app’s actual aspect ratio.
- Record source version, device/viewport, account role, timestamp, and post URL beside each original.

## Optional supporting image

Use one achievement/data-deletion image only if the main six already read clearly. Privacy functionality is important, but it should not displace the core hook from the first gallery positions.

## Rejection conditions

- Card values were manually seeded, mocked, or described as historical when the final live profile did not produce them.
- Image uses mocked API outcomes, `Local Demo`, `CreatorQA`, or a private locator.
- Screenshot shows a build different from the submitted version.
- Text overlaps, actions fall below the viewport, or keyboard focus obscures the primary claim.
- Caption says “community-built,” “live,” “secure,” or “mobile-ready” beyond accepted receipts.
