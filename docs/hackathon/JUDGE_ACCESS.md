## 90-second interactive path

1. Open the public game post and choose **Open today’s route**.
2. Choose **Ride Today’s Route**. The courier moves automatically; use Up/Down, W/S, swipe, or tap a lane. Three hits end the delivery.
3. Return to Menu and choose **Build a Course Tile**. Paint a cell, use **Certify Tile**, and inspect the safe-path/fix feedback. Publication requires Reddit sign-in.
4. Open **Roadbook** to see saved Daily Routes, community-built percentage, leaderboard, and private fixed-reason report controls.
5. Open **Share Card**. Every signed-in player sees the Route Passport: lifetime distance, featured tiles, clean deliveries, and failed deliveries with Reddit/image share actions. Use **Ride Daily Route** to return to today's course.
